# dotfiles
basic dotfiles with the stuff I use on my notebook1!11!1 mostly for studying and working purposes

i still haven't added anything as of 24/08/2026, but hey, maybe i will

list of software:
- [mango](https://github.com/mangowm/mango) (compositor)
- [wawa](https://github.com/swordreforge/wawa) (wallpaper daemon)
- [rs-yambar](https://github.com/fxmfxmfx/rs-yambar) (status bar)
- [anyrun](https://github.com/anyrun-org/anyrun) (launcher)
- foot (terminal)
- fnott (notification daemon)
- zed (editor)
- micro (terminal editor)
- matugen (color generation)
- swayosd (on-screen display)

complimentary software:
- brightnessctl (brightness control)
- gum (TUI dialog, option selection)
- yazi (tbh i only use it to select files without using xdg-desktop-portal or zenity)

and maybe more stuff in the future.

you could probably avoid installing most of the software here and most stuff would work, can't guarantee the scripts will work, however.

i made this to be pretty simple to maintain and update, but getting some of the software might be a pain in the ass on some distros (or freebsd i think), but hey, you probably know more than me on how to compile them lul.
